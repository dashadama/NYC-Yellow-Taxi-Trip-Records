# Запуск

1. Установить Java 17 и прописать `JAVA_HOME`
2. Клонировать репозиторий и создать виртуальное окружение:

git clone https://github.com/dashadama/NYC-Yellow-Taxi-Trip-Records.git
cd NYC-Yellow-Taxi-Trip-Records
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

3. Скачать данные по ссылке https://disk.yandex.ru/d/9bqbrGTK5HX4Sg и положить в папку data/
4. Запустить Jupyter и выполнить все ячейки ноутбука

# Выводы

1. Качество данных
   Всего очищено 7,77% поездок, осталось 22 127 340:
   - отрицательные суммы (3,27%)
   - нет расстояния или слишком большое расстояние (3,13%)
   - высадка не позже посадки (1,35%)
   - поездки дольше 6 часов (0,03%)
   - больше 6 пассажиров и даты вне периода (<0,001%)
   
  Аномалии в сырых данных: 
  - отрицательные суммы
  - расстояние 0 миль или больше 100 миль
  - поездки с ненулевым расстоянием, но одинаковым временем посадки и высадки
  - 9 пассажиров
  - даты за 2008 год
  - нет данных о погоде за 12 февраля 26 гоад

2. Результаты исследования
   
    **Какие маршруты и районы оказались самыми загруженными?**

     Самый загруженный район - Манхэттен, поездки:
     - Upper East Side South → Upper East Side North (152 516 поездок)
     - Upper East Side North → Upper East Side South (131 568 поездок)
   
    **Влияет ли погода и тип дня на спрос, стоимость и чаевые?**
     - во время осадков поездок на 6% меньше
     - в праздники поездок на 18% меньше, чем в будни дни
     - в выходные средний чек ниже

    **Какие дни оказались аномальными? Можно ли связать их с внешними факторами (праздники, погода)?**
     -  на Новый год во многих зонах поездок было больше обычного
     -  аномалии в количестве поездок 25 января и 23 февраля 26 года связаны с количеством осадков
